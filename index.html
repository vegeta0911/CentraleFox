Trois étapes, et c’est armé

Le fichier est prêt à l’emploi : rien à installer à côté, aucun compte à créer.

Téléchargez

Choisissez votre appareil plus haut et récupérez le fichier. Il pèse environ 10 à 12 Mo.

Autorisez-le

La première fois, votre ordinateur peut demander une confirmation. C’est normal pour un programme téléchargé.

Lancez-le

Le serveur démarre et attend votre centrale. Laissez la fenêtre ouverte tant que vous voulez qu’il tourne.

  1. Ouvrez votre dossier Téléchargements et double-cliquez sur le fichier .exe.
  2. Si une fenêtre bleue « Windows a protégé votre ordinateur » apparaît, cliquez sur Informations complémentaires, puis Exécuter quand même.
  3. Une fenêtre noire s’ouvre : le serveur tourne. Ne la fermez pas.
  1. Ouvrez le Terminal (Applications › Utilitaires) et tapez chmod +x ~/Downloads/myfox_local_server-macos-* puis Entrée.
  2. Dans le Finder, faites un clic droit sur le fichier, puis Ouvrir, et confirmez.
  3. Si le Mac refuse encore : Réglages Système › Confidentialité et sécurité › Ouvrir quand même.
  1. Placez le fichier sur l’appareil (clé USB ou téléchargement direct).
  2. Rendez-le exécutable : chmod +x myfox_local_server-*
  3. Lancez-le : ./myfox_local_server-aarch64 (avec le nom de votre fichier).

Questions fréquentes

Quel fichier pour mon Raspberry Pi ?

Pour un Raspberry Pi 4 ou 5 avec un système récent, prenez Raspberry Pi 64 bits. Pour un Raspberry Pi plus ancien ou un système 32 bits, prenez Raspberry Pi 32 bits.

Pour en être sûr, tapez uname -m sur le Pi : aarch64 veut dire 64 bits, armv7l veut dire 32 bits.

Comment savoir si mon Mac est « Apple » ou « Intel » ?

Cliquez sur la pomme en haut à gauche de l’écran, puis À propos de ce Mac. Si vous lisez « Puce Apple M1 » (ou M2, M3, M4…), prenez Mac Apple. Si vous lisez « Processeur Intel », prenez Mac Intel.

Mon ordinateur dit que le fichier est dangereux

Windows et macOS affichent un avertissement pour tout programme qui ne vient pas de leur boutique. Suivez les instructions plus haut pour l’autoriser. Téléchargez toujours le fichier depuis ce site, jamais depuis un lien reçu par message.

Le téléchargement ne démarre pas

Essayez la page de toutes les versions, lien en bas de page. Si le problème continue, vérifiez votre connexion ou essayez un autre navigateur.

Comment passer à une nouvelle version ?

Revenez sur ce site : il affiche toujours la dernière version. Arrêtez l’ancien serveur, téléchargez le nouveau fichier et lancez-le à la place de l’ancien.
